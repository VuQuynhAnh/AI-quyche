# Văn bản mẫu để demo

Upload các file `.docx` trong thư mục này qua **Trang quản trị → Văn bản** để có
dữ liệu demo ngay mà không cần chuẩn bị văn bản thật.

| File | Loại | Khi upload, tick "Tài liệu nhạy cảm"? |
|---|---|---|
| `quy-che-nghi-phep.docx` | Quy chế thông thường | Không |
| `quy-dinh-luong-thuong.docx` | Quy chế thông thường | Không |
| `noi-quy-lao-dong.docx` | Quy chế thông thường | Không |
| `quy-dinh-an-toan-thong-tin.docx` | Quy chế thông thường | Không |
| `quy-trinh-lam-viec-tu-xa.docx` | Quy chế thông thường | Không |
| `ho-so-luong-thuong-ca-nhan.docx` | **Tài liệu nhạy cảm** | **Có** |

File cuối cùng (`ho-so-luong-thuong-ca-nhan.docx`) dùng để minh hoạ tính năng
"tài liệu nhạy cảm": sau khi upload và tick chọn "Tài liệu nhạy cảm", hãy thử
hỏi chatbot ở trang nhân viên một câu liên quan (VD: "Lương của tôi tháng này
là bao nhiêu?"). Thay vì trả lời trực tiếp, chatbot sẽ từ chối và hướng dẫn
liên hệ quản trị viên — đồng thời tự động đưa hội thoại đó vào mục **"Cần admin
trả lời"** ở Trang quản trị → Lịch sử hỏi đáp.
